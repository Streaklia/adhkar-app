# دُعَاء | Doua & Tasbih

تطبيق إسلامي حديث وخفيف للأذكار والتسبيح اليومي، بواجهة عربية كاملة، وضع أسود OLED (`#000000`)، ويعمل دون اتصال بالإنترنت (PWA).

- **الرابط:** [https://adhkarr.vercel.app](https://adhkarr.vercel.app)

---

## المميزات

- **عداد التسبيح التفاعلي:** مساحة لمس دائرية مع إشارات بصرية واهتزازية (أخضر من 1 إلى 32، وأحمر عند 33)، مع دعم مفاتيح الكيبورد (`Space`, `Enter`).
- **شريط الوقت التلقائي:** يظهر أذكار الصباح أو المساء أو سنن الجمعة ومؤقت الغروب تلقائياً بحسب الوقت الحالي.
- **الأقسام الرئيسية:**
  - أذكار بعد الصلاة المفروضة (`/after-prayer`)
  - أذكار الصباح والمساء (`/adhkar`)
  - دليل الصلاة وقصار السور (`/prayer-guide`)
  - أدعية السفر والطريق مع القراءة الصوتية (`/travel`)
  - سنن وأدعية الجمعة وسورة الكهف (`/friday`)
  - أدعية الوالدين والأسرة مع مشاركة واتساب (`/family`)
- **وضع OLED الأسود:** خلفية سوداء نقية `#000000` لراحة العين وتوفير طاقة البطارية.
- **العمل دون اتصال:** دعم كامل للعمل بدون إنترنت عبر Service Worker و PWA.

---

## التشغيل محلياً

```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير
npm run dev

# أو بناء وتشغيل نسخة الإنتاج
npm run build
npm start
```

افتح المتصفح على: `http://localhost:3000`
