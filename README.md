# دُعَاء | Doua & Tasbih

تطبيق إسلامي حديث، فائق البساطة، وموجه للهواتف الذكية (Mobile-First) للأذكار والتسبيح اليومي، بواجهة عربية كاملة (RTL) مع وضع أسود OLED حقيقي (`#000000`) ودعم العمل دون اتصال بالإنترنت (PWA Offline).

---

## المميزات الرئيسية

### 1. العداد التفاعلي الذكي (Hero Tasbih)
- **مساحة لمس دائرية واسعة** تستحوذ على النصف العلوي من الشاشة لتسبيح سهل بيد واحدة.
- **إشارات بصرية واهتزازية حية:**
  - أثناء العد من 1 إلى 32 يتوهج القرص باللون الأخضر الزمردي (`#10B981`) مع صوت واهتزاز نقر خفيف.
  - عند بلوغ العدد **33** يتحول اللون فوراً إلى الأحمر التنبيهي (`#EF4444`) مع اهتزاز ثنائي قوي ونغمة وصول الهدف.
  - في الضغطة التالية بعد الـ 33، ينتقل العداد تلقائياً إلى الذكر التالي في الدورة المأثورة (سبحان الله -> الحمد لله -> الله أكبر -> تمام المائة).
- زر تصفير سريع وزر لإضافة **ذكر مخصص** مع تحديد العدد المستهدف.
- حفظ تلقائي للعدد والذكر النشط في `localStorage`.

### 2. شريط الوقت الذكي المباشر (Smart Time-Aware Banner)
- يعرض تلقائياً زراً سياقياً مخصصاً بحسب توقيت وجهاز المستخدم:
  - **يوم الجمعة:** إبراز سنن وأدعية الجمعة مع عداد تنازلي حي للوقت المتبقي حتى غروب الشمس (ساعة الاستجابة).
  - **الصباح (4 ص - 12 ظ):** إبراز أذكار الصباح.
  - **المساء (12 ظ - 4 ص):** إبراز أذكار المساء.

### 3. شبكة التنقل السداسية (2x3 Navigation Grid)
1. **بعد الصلاة** (`/after-prayer`): أذكار ما بعد السلام مع بطاقات تفاعلية تنقص تكراراتها بالضغط وتنتقل تلقائياً للبطاقة التالية.
2. **أذكار الصباح والمساء** (`/adhkar`): اختيار تلقائي للفترة مع إمكانية التبديل اليدوي وشريط إنجاز يومي.
3. **دليل الصلاة** (`/prayer-guide`): خطوات الصلاة بالترتيب الزمني مع أداة «اقترح لي سورة للصلاة» لاختيار سورتين عشوائيتين من جزء عم.
4. **أدعية السفر** (`/travel`): خط عالي التباين وكبير للسائقين، مع زر استماع صوتي (TTS) يعمل أثناء القيادة وبدون اتصال.
5. **يوم الجمعة** (`/friday`): قائمة سنن الجمعة، عداد الصلاة على النبي ﷺ، متتبع قراءة سورة الكهف، وعداد ساعة الاستجابة.
6. **الوالدين والأهل** (`/family`): تبويبات سريعة ومصنفة (أحياء، متوفين، إخوة، أبناء) مع زر مشاركة فوري بلمسة واحدة عبر واتساب (`WhatsApp`).

### 4. البحث الفوري بالحالة والمشاعر
- بحث فوري في جميع الأدعية مع اقتراحات سريعة لكلمات البحث: سفر، قلق، مطر، نوم، شفاء، استخارة، رزق، والدين.

### 5. وضع OLED الأسود الحقيقي والتخصيص
- زر تبديل علوي للوضع الأسود الحقيقي `#000000` لتوفير طاقة شاشات OLED وراحة العين.
- مفتاح تحكم فوري بالاهتزاز والأصوات.

### 6. جاهز للنشر على Vercel وPWA دون إنترنت
- مبني على Next.js 14 App Router مع مخرجات ساكنة خفيفة وسريعة جداً.
- مهيأ بـ Service Worker و Manifest للعمل كتطبيق مثبت على الهواتف دون إنترنت.

## تشغيل المشروع محلياً

```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

---

## النشر على Vercel

التطبيق مجهز بنسبة 100% للنشر الفوري على منصة Vercel:

1. ارفع المشروع إلى حسابك على GitHub أو GitLab.
2. ادخل إلى [Vercel Dashboard](https://vercel.com).
3. اختر **Add New Project** وحدد مستودع `doua-app`.
4. انقر على **Deploy** بدون الحاجة لأي إعدادات إضافية.
